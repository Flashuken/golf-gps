⛳ Golf GPS · Gestor de Biblioteca

Prepara y publica campos oficiales sin editar JSON a mano

1. Cargar tus campos

En Golf GPS abre Campos → Exportar copia. Después carga aquí ese archivo GolfGPS_Mis_Campos_....json. Todo se procesa en tu navegador: no se envía información a ningún servidor.

2. Elegir campos para publicar

Selecciona los campos revisados. Si ya has cargado una biblioteca existente, se conservarán sus campos y se añadirán los seleccionados. Si un identificador coincide, se actualizará ese campo.

Carga una copia de campos para empezar.

3. Descargar biblioteca lista para GitHub

Se generará golfgps_biblioteca.json en el formato que ya entiende Golf GPS Beta 1.2.7. Guarda una copia del archivo anterior antes de sustituirlo en GitHub.
